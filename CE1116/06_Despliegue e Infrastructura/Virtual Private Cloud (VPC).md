## 📚 Idea/Concepto 

Una VPC es un entorno lógicamente aislado dentro de la infraestructura de un proveedor de cloud público, que permite al ingeniero diseñar topologías de red completas de forma escalable y automatizada. Opera bajo principios de Redes Definidas por Software (SDN), donde componentes como routers, firewalls y NAT se consumen como servicios virtualizados gestionados mediante APIs o código. Su configuración parte de rangos de direcciones IP definidos mediante CIDR, lo que evita colisiones de red en entornos híbridos. Permite definir subredes, tablas de ruteo y reglas de acceso manteniendo el tráfico invisible para otros inquilinos. Puede extenderse hacia infraestructura on-premise mediante VPN Gateways, utilizar endpoints privados para acceder a servicios del proveedor sin exponer tráfico a internet, e interconectarse con otras VPCs mediante VPC Peering para escalar arquitecturas distribuidas.
