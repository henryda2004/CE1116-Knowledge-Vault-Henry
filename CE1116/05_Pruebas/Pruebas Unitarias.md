## 📚 Idea/Concepto 

Tipo de prueba de software que se enfoca en verificar el correcto funcionamiento de las unidades más pequeñas de un programa, con funciones o métodos individuales. Cada una valida que una parte específica del código produzca el resultado esperado cuando recibe ciertas entradas.
